# Tread & Go — tire shop

A tire shop and mobile tire-fitting app, in English and Kurdish (Sorani).

ئەپێکی فرۆشتنی تایە و خزمەتگوزاری بەستنی تایە لە شوێنی کڕیار، بە زمانی کوردی و ئینگلیزی.

## Features / تایبەتمەندییەکان

- Pick a car and see tires that fit, plus similar sizes within 3% of the factory diameter
- Each tire shows a photo, price, size, load and speed rating, DOT manufacture date and replace-by date
- Book a technician to fit tires, fix a flat, rotate or swap a spare at the customer's location
- English / کوردی switch, with a right-to-left layout for Kurdish

## Run it / کارپێکردن

Open `index.html` in a browser. No install or build step is needed.

`index.html` لە وێبگەڕێکدا بکەرەوە. پێویست بە دامەزراندن نییە.

## Note

In this standalone file, bookings and the cart are saved in the visitor's browser only, and the owner's **Manage** section (adding tires with photos) works only in the published claude.ai version, which stores tires in a shared database.
